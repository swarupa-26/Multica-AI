# Multica-AI
A repository documenting Multica AI, its key features, MCP server integration, and an Expense Tracker project. Includes learning notes, implementation details, and practical examples of AI-powered task automation.

## Objectives
- Understand the Multica AI platform and its key features.
- Explore AI agents, projects, chat, inbox, and squads.
- Learn how MCP (Model Context Protocol) enables AI agents to interact with external tools.
- Implement an Expense Tracker project with an integrated Expense MCP server.
- Document practical experiments, challenges, and learnings.

## Key Features Explored
- **Projects:** Organize and manage AI-powered work.
- **Agents:** Configure agents to perform specific tasks.
- **Chat:** Interact with AI agents using natural language.
- **Inbox:** Manage task-related updates and notifications.
- **Squads:** Explore collaboration between agents.
- **MCP Integration:** Connect AI agents with external tools through MCP servers.

## Project: Expense Tracker
The Expense Tracker demonstrates how an AI agent can interact with expense-management tools through an MCP server.

The integration explores:
- Adding expenses.
- Retrieving expense records.
- Calculating total expenses.
- Deleting expenses.

*Note: The supported functionality depends on the implemented MCP server and its configuration.*
